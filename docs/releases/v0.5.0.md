Review alur kerja dan pembaruan workspace Moz Checker.

- **Melanjutkan data lama:** aplikasi membuka workspace tersimpan dengan input baru tertutup dan banner **Lanjutkan pemeriksaan** beserta jumlah domain tersisa. Pilih **Semua pemeriksaan** untuk meneruskan seluruh sesi pecahan lama. Tidak perlu impor ulang.
- **Resume dari checkpoint:** pekerjaan yang sudah sampai OPR, Wayback atau Moz melanjutkan tahapnya; hasil domain selesai dipertahankan. Resume satu sesi tidak menjalankan sesi lain yang masih antre.
- **Retry terarah:** hanya sumber yang perlu diperiksa ulang yang dijadwalkan. No-key/kuota Moz bisa dicoba setelah pengaturan diperbaiki; paid request failed/reserved/uncertain tetap tidak diulang otomatis.
- **Concurrency tersedia:** Pengaturan → Aturan hunting → Concurrency RDAP/DNS, 1–32, default 8. Rate limit tiap server tetap berlaku; Wayback/Moz tetap serial.
- **UI lebih terarah:** permukaan putih/slate, aksen biru, tipografi dan spacing konsisten, tabel padat, fokus keyboard, status operasi terlihat dan generator berlabel. Tidak ada kartu dashboard atau slogan.
- **Ketahanan proses:** marker paid request dan kuota disimpan atomik; timeout juga berlaku saat membaca body; angka OPR berbentuk teks didukung; cache/bootstrap gagal ditangani; CSV lama dipertahankan bila ekspor gagal.
- **Workflow build/rilis:** paket dibangun dalam folder bersih, tools publisher diuji di CI, dan bukti smoke resume diwajibkan sebelum rilis.

Tutup versi lama dan ekstrak **seluruh ZIP** ke folder baru. Memerlukan Microsoft .NET 10 Desktop Runtime x64. Buka dengan akun Windows/lokasi data yang sama; SQLite, hasil lama dan kuota tetap dipakai. Gunakan **Lanjutkan** untuk pekerjaan tertunda, **Ulang sumber gagal** untuk kegagalan sumber. Log sebelum versi yang merekam event persisten tidak dibuat-buat.
