Rilis awal Expired Domain Checker untuk Windows 10/11 64-bit. Status **MVP preview**.

### Unduh dan jalankan

1. Unduh `MozChecker-Windows-x64.zip` di bagian Assets.
2. Ekstrak seluruh ZIP, lalu buka `MozChecker/MozChecker.exe`. Jangan memindahkan hanya file EXE; folder `_internal` harus tetap menyertainya.
3. Buka **Pengaturan & API key** jika ingin memakai Open PageRank atau Moz. Python tidak perlu diinstal untuk menjalankan paket portable ini.

`SHA256SUMS.txt` berisi checksum paket. Di PowerShell, gunakan `Get-FileHash .\MozChecker-Windows-x64.zip -Algorithm SHA256` dan cocokkan hasilnya. Aplikasi belum ditandatangani secara digital.

### Fitur

- Input/impor CSV/TXT dan generator kata kunci + TLD, maksimal 1.000 domain unik; normalisasi IDN dan Public Suffix List.
- Pemeriksaan RDAP + DNS dengan bukti, status konservatif, registrar, dan tanggal kedaluwarsa.
- Adapter Open PageRank, pemindaian sampel Wayback, serta Moz DA/PA/Spam Score untuk domain finalis.
- SQLite lokal, cache, antrean hunting, jeda/lanjut, batas kuota Moz, filter, dan ekspor CSV.
- API key disimpan melalui Windows Credential Manager; tidak ada server pusat.

### Batasan preview

- Moz mendukung **Links API v2 dengan Access ID + Secret**, belum token JSON-RPC v3. Hak akses akun, harga, dan kuota provider perlu diverifikasi pengguna; batas rows aplikasi adalah penghitung lokal, bukan saldo akun.
- Pengujian pipeline memakai respons simulasi tanpa key/kuota berbayar. Build dan smoke test otomatis tidak menggantikan pengujian manual API key, DNS jaringan pengguna, dan alur pembelian di registrar.
- Tidak ada fallback WHOIS; TLD tanpa RDAP/PSL yang didukung tetap unknown. Watchlist/notifikasi dan analisis spam lanjutan belum tersedia.
- Pemindaian arsip menggunakan sampel dan dapat salah klasifikasi. Ketersediaan domain dapat berubah; hasil bukan jaminan bisa dibeli.

Lihat README dan docs/VALIDATION.md untuk konfigurasi serta bukti validasi terperinci.
