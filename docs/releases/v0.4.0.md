Pembaruan UI, pemrosesan daftar besar, dan log pemeriksaan.

### Satu daftar, satu pemeriksaan

- **Pemecahan per 1.000 domain dihapus.** Satu file atau daftar input menjadi satu pemeriksaan penuh. Tidak ada batas domain 1.000 pada parser, penyimpanan, atau generator; batas file 5 MB juga tetap dihapus.
- Progres menampilkan **total, selesai, belum selesai, menunggu, dan diproses** sesuai cakupan yang dipilih.
- Data dari hunting pecahan versi lama dipertahankan. Tampilan awal **Semua pemeriksaan** menggabungkan progres dan hasil seluruh data lama. Pilih **Lanjutkan** pada cakupan itu untuk melanjutkan semua pemeriksaan yang dijeda. Tidak ada penggabungan destruktif atau penghapusan riwayat lama.
- Input besar menampilkan pratinjau 200 dari N domain dengan label jelas; seluruh N disimpan. Worker membaca data bertahap dari SQLite, bukan memuat seluruh hasil ke RAM.

### UI dan log

- Toolbar, input yang bisa dilipat, dan tabel native Windows. Slogan, sidebar, tema mint gelap, dan kartu dashboard dihapus.
- **Available**: hanya hasil available. **Hasil lainnya**: hasil registered/unknown dan status non-available lainnya. **Antrean / proses**: domain yang belum selesai, terpisah dari log.
- **Log kejadian** menyimpan kejadian aktual dengan waktu komputer, nomor urut, pemeriksaan, domain, tahap dan status; **terbaru di atas**. Domain yang baru mengantre tidak ditulis seolah-olah sudah diperiksa. Menunggu Moz dibedakan dari permintaan yang sedang diproses.
- Log tersimpan saat aplikasi ditutup. Saat membaca halaman riwayat, posisinya dikunci; tombol **Terbaru** mengikuti kejadian baru lagi. Data lama tetap memiliki waktu sumber aslinya di hasil/detail; aplikasi tidak membuat-buat waktu event lama yang memang belum pernah direkam.
- Tabel menampilkan 200 baris per halaman dengan jumlah keseluruhan. Ini pagination tampilan, bukan batas pemeriksaan. Pencarian, filter, pengurutan dan ekspor berlaku atas seluruh cakupan; ekspor CSV mencakup semua halaman yang cocok.

### Instalasi

Tutup versi sebelumnya. Unduh dan ekstrak **seluruh ZIP ke folder baru**, lalu buka `MozChecker/MozChecker.exe`; jangan hanya mengganti EXE karena DLL juga berubah. Memerlukan **Microsoft .NET 10 Desktop Runtime x64**: https://dotnet.microsoft.com/en-us/download/dotnet/10.0. Lokasi SQLite/kuota dan Windows Credential Manager tetap sama. Indeks dan penghitung baru dibuat secara transaksional; data hasil lama tidak dihapus.
