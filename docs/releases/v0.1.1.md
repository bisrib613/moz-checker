Perbaikan tampilan hasil Expired Domain Checker untuk Windows x64.

- Tabel **Hasil available** hanya menampilkan domain available. Domain registered (misalnya google.com), redemption, pending delete, unknown, dan yang masih menunggu tampil di **Log pemeriksaan**, beserta bukti RDAP/DNS dan kesalahan.
- Penghitung **Sudah diperiksa**, **Available**, dan **Registered** dipisahkan. Jumlah pemeriksaan selesai tidak lagi terkesan sebagai jumlah domain tersedia.
- Ekspor CSV hanya mencakup hasil available sesuai filter. Data job lama tetap tersimpan dan langsung mengikuti tampilan baru; tidak perlu menghapus database.

Unduh `MozChecker-Windows-x64.zip`, ekstrak seluruh folder, lalu jalankan `MozChecker/MozChecker.exe`. Python tidak diperlukan. Tutup aplikasi versi sebelumnya sebelum mengganti folder portable; data tetap berada di `%LOCALAPPDATA%/MozChecker`.

Checksum tersedia di `SHA256SUMS.txt`. Ini masih pre-release dan belum ditandatangani. Batasan integrasi sama seperti v0.1.0: Moz v2 Access ID + Secret (bukan token v3), API berkey nyata dan pengujian manual akun pengguna belum tervalidasi. Available bukan jaminan transaksi berhasil; konfirmasi kembali ke registrar.

Validasi rilis: 53 tes otomatis dan smoke test desktop; executable Windows juga harus lolos smoke test pada workflow build sebelum paket ini dapat dipublikasikan.
