C# + .NET 10 WPF preview untuk Windows 11 x64. Paket ini tidak berisi Python, PyInstaller, atau Qt.

### Unduh dan jalankan

1. Unduh `MozChecker-Windows-x64.zip` (sekitar **1,6 MB**) dari bagian Assets.
2. Pasang **Microsoft .NET 10 Desktop Runtime x64** dari https://dotnet.microsoft.com/en-us/download/dotnet/10.0 jika belum tersedia. Pilih **Desktop Runtime**, bukan hanya ASP.NET Runtime. Runtime dipasang terpisah dan tidak termasuk ukuran ZIP.
3. Ekstrak seluruh folder ZIP, lalu buka `MozChecker/MozChecker.exe`. Semua DLL harus tetap bersama EXE. Tutup aplikasi versi lama sebelum membuka versi ini.

### Perubahan

- Antarmuka native WPF; tabel hasil hanya berisi domain **available**. Registered, redemption, pending delete dan unknown ada di log.
- RDAP + DNS, OPR, Wayback, Moz v2, antrean, jeda/lanjutkan, filter dan ekspor CSV.
- Data SQLite dan kuota lokal dipertahankan. Pembukaan pertama database lama membuat backup `checker.sqlite3.before-dotnet.bak`. Job lama dijeda sampai memilih Lanjutkan.
- Kunci disimpan di Windows Credential Manager. Moz memakai legacy Links API v2 access ID + secret, bukan token v3.

Catatan penahanan publikasi di README dalam ZIP merekam status saat build dibuat. Halaman rilis ini mencatat keputusan terbaru untuk menerbitkan preview dengan hash paket yang tetap sama.
