Redesign workspace Expired Domain Checker untuk Windows x64.

### Tampilan baru

- Sidebar khusus input, impor CSV/TXT, generator, dan kuota Moz lokal; area hasil lebih luas.
- Kartu Available, Sudah diperiksa, Riwayat lolos, dan Registered yang terpisah dan berasal dari hasil job.
- Tabel hanya memuat domain available. Registered dan status lain tetap berada di Log pemeriksaan.
- Pencarian domain tanpa membedakan huruf besar/kecil, filter dengan reset, serta empty state yang menjelaskan kondisi baru, tidak ada kandidat, atau tidak ada kecocokan.
- Metrik OPR/Moz lebih dekat ke kolom domain; registrar/tanggal dan bukti teknis tersedia melalui tombol Bukti pemeriksaan atau klik dua kali baris, dalam dialog terpisah.
- Pengaturan API dan aturan hunting dipisah menjadi dua tab. Form memiliki label dan kontrol native dengan indikator serta fokus yang terlihat.
- Layout compact pada tinggi jendela <800px, sidebar/settings dapat digulir, minimum workspace 1040×700. Font dan ikon tersedia lokal, tanpa layanan font eksternal.
- Refresh latar belakang menjaga seleksi tabel dan teks bukti ketika data tidak berubah.

Shortcut: Ctrl+Enter mulai/antrekan, Ctrl+O impor, Ctrl+F cari hasil, Ctrl+koma pengaturan. Tombol ekspor hanya aktif jika ada hasil available yang tampil.

### Unduh / update

Unduh `MozChecker-Windows-x64.zip`, ekstrak seluruh folder, lalu jalankan `MozChecker/MozChecker.exe`. Python tidak diperlukan. Tutup versi sebelumnya sebelum mengganti folder portable; data lokal di `%LOCALAPPDATA%/MozChecker` tetap kompatibel. Jangan memindahkan hanya EXE tanpa folder `_internal`.

Checksum tersedia di `SHA256SUMS.txt`. Publisher hanya menerima artefak dari CI yang lulus dan memverifikasi checksum, ZIP, PE x64, serta plugin Qt Windows sebelum publikasi.

### Validasi dan batasan

57 tes otomatis mencakup pipeline dan interaksi UI baru; smoke test executable Windows wajib lulus pada workflow build. Tampilan diperiksa di cloud pada 1440×900 dan 1040×700. Rasio kontras teks tema diukur ≥4,5:1. Pengujian manual high-DPI/screen reader Windows dan akun API nyata belum dilakukan.

Masih pre-release, belum ditandatangani. Perubahan ini berfokus pada antarmuka; pipeline, SQLite, dan aturan ketersediaan tetap sama. Moz tetap Links API v2 (Access ID + Secret), belum token v3. Available bukan jaminan domain bisa dibeli; konfirmasi kembali di registrar.
